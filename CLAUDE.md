# CLAUDE.md

Проект: сайт цветочной мастерской. Django 5, PostgreSQL, Redis, Celery, pydantic, HTMX, Alpine, Tailwind, Docker.

@tech.md
@DEV.md

## Источник истины

`tech.md` — **единственный источник истины**: схема БД, слаги, контракты задач Celery, формат URL и фильтров, набор UI-примитивов, конвенции. Подчиняйся дословно.

`DEV.md` — задачи слайсами, критерии приёмки, требуемые тесты. Одна задача за раз, по порядку стадий.

Текущая версия ядра — в шапке `tech.md`. Версия в твоём контексте старше той, что в файле — перечитай файл.

## Главное правило

**Контракты не выдумываются.** Нет нужного поля, модели, задачи, URL, параметра или компонента в `tech.md` — СТОП. Не пиши код с выдуманным типом и не «добавлю пока так, потом поправим».

Выдай блок:

```
CONTRACT GAP
Что нужно:
Зачем:
Предлагаемая форма:
Влияние:
Временное решение:
```

Затем контракт дописывается в `tech.md`, версия ядра бампается, и работа продолжается уже с контрактом.

## Границы

Не меняй без явной причины и отдельного коммита: `tech.md`, `config/`, `templates/base.html`, `templates/layout/`, `templates/ui/`, `tailwind.config.js`, `clients/`.

Миграции создаются внутри слайса, но **всегда отдельным коммитом** и просматриваются построчно.

## Быстрые правила

- Изображения в PostgreSQL не хранятся. В базе путь и метаданные, файлы через storage-объекты. Оригиналы фото работ — в `private_storage`, публично недоступны.
- Рендишены генерируются **только** для `WorkImage`. Остальные изображения сжимаются один раз при загрузке и рендерятся через `image_simple.html`.
- `os.environ` в коде нет. Только `config/settings_schema.py`.
- Задача Celery имеет **явное имя** в декораторе, принимает один именованный аргумент `payload: dict` и парсит его pydantic-моделью из `contracts.py`. Каждая задача идемпотентна и имеет тест на это. Сетевые вызовы — вне транзакций.
- Переводные поля читаются только через `{{ obj|tr:"field" }}`; `tr_html` — исключительно для полей, санитизируемых bleach (`StaticPage.body`, `Post.body`).
- UI собирается из примитивов `templates/ui/`. Самописной разметки вместо примитива быть не должно. Значения Tailwind в квадратных скобках запрещены.
- Тесты пишутся из критериев приёмки задачи в `DEV.md`, не из реализации.
- Код, комментарии, коммиты и PR — по-английски. Коммиты: `type(scope): summary`, тип из `feat|fix|test|refactor|chore|docs`.
- Пользовательские строки — через `gettext`, переводы на украинский и русский.
- Ссылки `tel:`, Viber и Telegram активны всегда, при любых настройках сайта.
